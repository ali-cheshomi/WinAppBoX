## Introduction

**WinAppBoX** is a customizable and animated app bar for Windows that allows you to manage and quickly launch your favorite applications in a clean and modern environment.

With WinAppBoX, you can organize your applications in one convenient place and launch them with a single click. The application includes features such as 90-degree rotation, square mode, drag and drop support, window pinning, Always on Top mode, and System Tray support.

---

## Features

### Application Management

- Add applications and shortcuts
- Support for up to **25 applications**
- Add applications using **Drag & Drop**
- Launch applications with a single click
- Easily manage your applications
- Display application icons in an organized and accessible interface

### Display Modes

- Rotate the user interface up to **90 degrees**
- Support for full or **square mode**
- Designed for different screen positions and sizes
- Modern and animated user interface

### Always on Top

When **Always on Top** mode is enabled, WinAppBoX remains above other windows, providing quick and easy access to your applications.

### Pin Feature

The **Pin** feature allows a selected application to always open at the same position on the screen.

With this feature:

- The application window position is saved
- The application opens at the same location the next time it is launched
- The positions of other applications remain unchanged
- Your windows stay more organized

### System Tray

WinAppBoX supports the Windows System Tray.

When this feature is enabled:

- WinAppBoX is removed from the main Windows taskbar
- WinAppBoX continues running in the System Tray
- The application runs in the background without taking up taskbar space
- You can reopen WinAppBoX by clicking its icon in the System Tray

## Usage

### Adding an Application

To add an application to WinAppBoX:

1. Locate the application executable or shortcut.
2. Drag it into WinAppBoX.
3. The application will be added to the application list.
4. Click the application icon to launch it.

> Note: The maximum number of applications is limited to 25.

### Reordering Applications

To change the order of your applications, click and hold an application icon, then drag it to the desired position.

### Using the Pin Feature

1. Launch the desired application.
2. Enable the **Pin** option.
3. Move the application window to the desired position.
4. The application will open at the same position in future launches.

### Enabling Always on Top

To keep WinAppBoX visible above other windows, enable the **Always on Top** option.

### Moving WinAppBoX to the System Tray

To hide WinAppBoX from the Windows taskbar, enable the **System Tray** option.

After enabling it, WinAppBoX will remain accessible from the System Tray near the Windows clock.
